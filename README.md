# Week 1 – Dart Fundamentals

A small Dart programming exercise demonstrating variables, strings, arithmetic operations, and reading input from the console.

## Contents

| File | Description |
|---|---|
| `1(b)` | Dart console program that reads an integer, performs addition, subtraction, multiplication and division, and prints a full name |
| `Screenshot 2026-08-18 135247.png` | Captured program output |

## Concepts demonstrated

- Declaring string, integer and double variables
- Performing basic arithmetic
- Reading console input with `stdin.readLineSync()`
- Parsing text input into an integer
- String interpolation with `$`

## Run the exercise

1. Install the [Dart SDK](https://dart.dev/get-dart).
2. Open the repository in an editor.
3. The source file is named `1(b)` and has no extension. Rename a copy to `1_b.dart` if your editor or Dart tooling requires the `.dart` extension.
4. Run:

   ```bash
   dart 1_b.dart
   ```

5. Enter an integer when prompted.

> This repository contains an individual exercise and its output image, not a complete Flutter application. A `pubspec.yaml` or Flutter project scaffold is not included.

## Learning objective

Practice Dart's basic types, console input, expressions, and formatted output before moving on to Flutter UI development.
